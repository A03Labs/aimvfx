# AIM VFX — Studio website v2 (work-first)
A "show, don't tell" portfolio direction influenced by minimal motion-designer portfolios: a one-line intro, big text category filters with counts, and a dense 16:9 work grid captioned "Discipline · Client ― Project". Project pages lead with frames; the copy is one line.
- **Index:** filter All / Events / Products / Business / Showreels. Hover plays the tile.
- **Project:** big title, meta row, `<image-slot>` frames (drag real stills/GIFs in, and they persist), next project.
- **Studio:** statement, showreel, services as credits-style lists.
- **Contact:** giant email.
Light theme by default (header toggle for dark). Grid tiles use `Poster`, animated brand-motif compositions standing in for real project GIFs; swap `<Poster>` for `<img>`/`<video autoplay muted loop>` when work assets exist.
**This is the official AIM VFX website.** v1 (pillar-led, dark) in `../website/` is archived for reference only.
