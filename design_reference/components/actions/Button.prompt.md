Pill-shaped call-to-action button. Use primary for the single main action per view (e.g. "Start a project").
```jsx
<Button variant="primary" iconRight={<span>→</span>}>Start a project</Button>
<Button variant="secondary">See our work</Button>
```
Variants: primary (indigo), secondary (outline, inverts on hover), inverse (white on dark), ghost, link. Sizes sm/md/lg. Arrow icons nudge right on hover.
